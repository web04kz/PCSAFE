# PC CHECKER
Статический сайт (HTML/CSS/JS, без сборки и сервера).

## Локальный запуск
Модули ES не работают с file:// — запустите любой HTTP-сервер в папке проекта, например `python -m http.server 8000`, и откройте http://localhost:8000.

## GitHub Pages
1. Создайте репозиторий и загрузите содержимое папки (index.html в корне).
2. Settings → Pages → Source: Deploy from a branch → main / root.
3. Через минуту сайт откроется по адресу https://ИМЯ.github.io/РЕПОЗИТОРИЙ/ (пути в проекте относительные).
